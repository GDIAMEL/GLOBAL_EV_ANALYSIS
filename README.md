# GLOBAL_EV_ANALYSIS

This project explores global electric vehicle (EV) data to uncover trends, correlations, and insights related to EV adoption, infrastructure development, and powertrain technology over time.

##  Project Structure

- **Data Loading** – Import and preview the dataset.
- **Exploratory Data Analysis (EDA)** – Summary statistics and visualizations to understand the distribution and relationships in the data.
- **Data Cleaning** – Handle missing values, standardize formats, and prepare data for analysis.
- **Visualization** – Create insightful plots (boxplots, heatmaps, etc.) to highlight patterns over time.
- **Correlation Analysis** – Assess linear relationships between key variables.
- **Insights & Conclusion** – Summarize key findings and trends in EV growth.

## Key Features

- Distribution of EV types and infrastructure over time
- Identification of future projections through outlier detection
- Correlation analysis between deployment year and adoption metrics
- Use of Seaborn and Matplotlib for rich visual storytelling

## Technologies Used

- Python
- Google Colab
- Pandas, NumPy
- Seaborn, Matplotlib

## Example Outputs

- Boxplots showing powertrain deployment timelines
- Heatmaps illustrating variable correlations

## Conclusion

The analysis reveals a growing trend in electric vehicle adoption globally from 2015 to 2024, with significant infrastructure development and early projections up to 2035. Fuel Cell Electric Vehicles (FCEVs) are still emerging, while Battery Electric Vehicles (BEVs) dominate current and projected trends.
